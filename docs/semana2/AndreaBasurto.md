## Mis historias de usuario

> Entre 5 y 7 historias en formato "como [rol] quiero [acción] para [beneficio]", pensadas desde distintos roles o necesidades del producto que el equipo está diseñando.

1. Como asistente sin experiencia en tecnología quiero crear mi cuenta con mi correo o mi huella digital, sin manejar llaves privadas, para usar el sistema igual que cualquier otra app de boletos.
2. Como asistente quiero que mi boleto muestre un código QR que cambie cada pocos segundos para que nadie pueda copiarlo y usarlo en mi lugar.
3. Como organizador de eventos quiero recibir el pago de cada venta directamente en mi cuenta para no depender de una plataforma que retenga mi dinero.
4. Como asistente quiero recibir un reembolso automático si el evento se cancela para no tener que reclamarlo manualmente.
5. Como personal de acceso quiero que la verificación funcione aunque la conexión a internet sea inestable para no detener el ingreso del público.
6. Como pasajero quiero recibir una compensación automática si la aerolínea me niega el embarque para no perder días haciendo trámites.
