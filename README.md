# TrustTix

## Requisitos

- [Node.js](https://nodejs.org/) 20.19 o superior (incluye npm).
- Git.

## Instalación

```bash
git clone https://github.com/DanielRosalesAlanis/Builders101.git
cd Builders101/frontend
npm install
```

## Cómo correrlo

```bash
npm run dev
```

Abre <http://localhost:5173> en el navegador. Para verlo desde el celular en la misma red, usa la dirección "Network" que muestra la terminal.
